# 自动赛项目资料

比赛源代码、模型权重、ROS 依赖及规则材料的权属/再分发许可需分别确认。本仓库暂不声明统一许可证。若公开发布，应先确认代码来源、权重训练与授权来源，以及引用的第三方组件许可。

robot/platform 是机器人工作区中底层包的源码快照，来源为 https://github.com/nxrobo/spark_noetic。上游顶层 BSD-3-Clause 许可原文保存在 robot/platform/licenses/NXROBO-BSD-3-Clause.txt，各包自身 LICENSE、版权头与 package.xml 中的许可字段一并保留。来源、包清单和逐文件 SHA-256 分别记录在该目录的 packages.json 和 source-manifest.csv。不同包的声明不能互相替代，也不为比赛改动或模型自动授予相同许可。

此仓库不包含场地地图、机器人定位标记文件、相机采集数据、原始训练图片/标签、基础预训练权重、训练缓存或模型备份。实际运行需要在机器人上提供对应地图与标记点文件。
